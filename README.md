# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。字幕按时间顺序进入待确认区，确认后进入直播区；校对员可以快速处理标点、专有名词、发言人和数字，并在弱网或断线时继续工作。

## 功能

- 多频道值守：主会场、分会场、采访间各有独立的待确认队列、正在编辑的片段、术语规则、直播时间线和连接状态；顶部频道条一键切换，每个频道实时显示连接状态与积压数。
- 草稿隔离：在频道间来回切换不会把编辑草稿、术语表单或队列过滤条件串到其他频道；撤销/重做历史也按频道分别保存。
- 断线恢复：每个频道可单独模拟断线并继续校正，确认内容进入该频道离线发件箱；恢复后只按本频道的序号和开始时间顺序合并，重复片段只在本频道内复查。
- 频道记忆：页面重开后自动回到上次值守的频道（含各频道草稿），字号等全局界面偏好统一保存。
- 实时待确认队列：每个频道按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 字幕编辑：修改发言人、正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后进入当前频道的直播时间线；导出 SRT 只包含当前频道，文件名带频道名。
- 离线校正：断线后仍可在当前频道继续修改和确认，确认内容进入该频道离线发件箱。
- 顺序合并：恢复连接后按本频道序号和开始时间排序合并，并在本频道内重新检查重复和过期内容，不影响其他频道。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间和队列积压都会明确展示。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做。
- 本地持久化：多频道工作台（各频道修改、术语规则、连接状态、上次值守频道）和界面字号保存在 `localStorage`（v2 键），首次打开会自动迁移旧版单频道草稿为主会场频道。

## 技术栈

- Lit 3
- TypeScript 5
- Carbon Web Components 2
- Carbon Styles
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。每个频道的模拟队列每 5 秒独立更新，可在当前频道用“模拟断线”和“恢复并合并”演示离线流程。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
