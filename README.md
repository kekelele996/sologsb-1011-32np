# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。一场大会同时有主会场、分会场和采访间三路字幕，三个频道各自维护待确认队列、编辑草稿、术语规则、连接状态与直播输出，互不串用。字幕按时间顺序进入当前频道待确认区，确认后进入该频道直播区。

## 功能

- 多频道值守：主会场、分会场 A、采访间各有独立队列、序号、正在编辑的片段、术语规则、连接状态和直播时间线；频道栏实时显示三路延迟、积压与离线发件箱角标。
- 草稿不串频道：切换频道只换值守指针，编辑中文本、列表过滤器、术语表单草稿和撤销/重做栈都按频道保存。
- 频道内离线流程：断线只影响本频道，恢复后按本频道序号和开始时间合并，重复片段只在本频道内比对（不同频道同文本不算重复）。
- 独立导出：导出 SRT 只包含当前频道已确认字幕，文件名带频道标识。
- 记住值守位置：当前频道、各频道队列与草稿保存在 `localStorage`，重开页面自动回到上次值守的频道（旧版单频道存档会迁移为主会场）。
- 实时待确认队列：按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 字幕编辑：修改发言人、正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后进入本频道直播时间线，支持按频道导出 SRT。
- 离线校正：单频道断线后仍可继续修改和确认，确认内容进入该频道离线发件箱。
- 顺序合并：恢复连接后按本频道序号和开始时间排序合并，并重新检查重复和过期内容；其他频道不受影响。
- 频道切换：点击频道栏或使用 `Alt + 1/2/3` 切换，三路模拟信号每 5 秒同时推流。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间和队列积压都会明确展示。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + 1/2/3` 切换频道，`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做（撤销/重做各自独立）。
- 本地持久化：各频道修改、术语规则、连接模拟状态、当前值守频道和全局界面字号保存在 `localStorage`。

## 技术栈

- Lit 3
- TypeScript 5
- Carbon Web Components 2
- Carbon Styles
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。三个频道的模拟队列每 5 秒自动更新，可在当前频道用“模拟本频道断线”和“恢复并合并”演示该频道的离线流程，其余频道继续推流。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
